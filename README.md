# Unichat

Unichat is a campus-focused social prototype built with React and Vite. It simulates a student community app with sections for home, communities, friends, projects, grades, profiles, and moderation.

## Features

- Sign in and demo auth flow
- Community chat-style interface
- Friend discovery and status cards
- Project collaboration panels
- Grade tracking and planning views
- Profile management
- Moderator queue for reported content
- Light and dark mode toggle

## Tech Stack

- React
- Vite
- React Router
- CSS custom properties for themeing

## Getting Started

1. Install dependencies:
   npm install
2. Run the app locally:
   npm run dev -- --host 0.0.0.0
3. Open the local Vite URL in the browser.

## Build

npm run build

## Project Status

This is a frontend prototype for exploration and design iteration. It uses mock data and demo interactions rather than a real backend.

## Notes

- The app is designed as a concept prototype for a university community experience.
- Branding and product direction are still open for iteration.
- The moderation features are demo-level and meant for UX exploration.
